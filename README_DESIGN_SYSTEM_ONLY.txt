================================================================================
WIFI VOUCHER SCANNER DESIGN SYSTEM
================================================================================

Visual Language: Soft Neumorphic & Modern Clean
Purpose: Design System Reference for Printer V1

CORE DESIGN PRINCIPLES:
1. Soft Tactile Depth (Neumorphism):
   - Soft off-white / light slate base canvas (#E9EEF4).
   - Raised surfaces with dual-tone lighting (highlight on top/left, soft shadow on bottom/right).
   - Inset / sunken surfaces for inputs and search boxes.
   - Smooth corner radiuses (14dp - 20dp) for organic, friendly tactile feel.

2. Color Hierarchy:
   - Primary Action: Ruijie Blue (#1E6DEB) to Vibrant Blue (#2563EB)
   - Secondary / Accent: Sky Blue (#0EA5E9) & Cyan (#06B6D4)
   - Status Active / Not Used: Emerald Green (#10B981)
   - Status Used: Royal Blue (#2563EB)
   - Status Expired: Rose Red (#EF4444)

3. Component Library:
   - NeumorphicCard: Soft embossed container with tactile depth.
   - NeumorphicButton: Raised pill / rounded button with ripple and hover feedback.
   - NeumorphicIconButton: 48dp accessible circular / rounded square action button.
   - NeumorphicTextField: Recessed / sunken input box for queries and form fields.
   - NeumorphicFilterChip: Interactive filter pill with raised inactive and vibrant active state.
   - NeumorphicStatusBadge: Distinct status pill with clean font hierarchy.
   - AppBottomNav: Neumorphic bottom navigation bar with active pill indicator.
